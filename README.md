# 🔎 Pencarian Dampingan 2026

Aplikasi web untuk mencari data Duta Pendamping kampung dan sekolah di tahun 2026.

## 📋 Deskripsi

Sistem pencarian interaktif yang memudahkan Anda untuk:
- **Cari Duta**: Ketik nama Duta untuk melihat semua kampung/sekolah yang didampinginya
- **Cari Kampung/Sekolah**: Ketik nama tempat untuk mengetahui siapa Duta pendampingnya
- **Filter**: Saring berdasarkan tipe (Kampung atau Sekolah)

## 🚀 Cara Menggunakan

1. Buka aplikasi di: [https://binpotmas2025-crypto.github.io/dampingan/](https://binpotmas2025-crypto.github.io/dampingan/)
2. Ketik nama Duta, Kampung, Sekolah, Kelurahan, atau Kemantren di kotak pencarian
3. Gunakan filter untuk menyaring hasil (Semua, Kampung, atau Sekolah)
4. Hasil pencarian akan ditampilkan secara real-time

## 📊 Fitur

✅ Pencarian real-time tanpa perlu refresh  
✅ Filter berdasarkan jenis (Kampung/Sekolah)  
✅ Highlight hasil pencarian  
✅ Responsive design (mobile-friendly)  
✅ Menampilkan data lengkap: Duta, Lokasi, KHK, Kelurahan, Kemantren
